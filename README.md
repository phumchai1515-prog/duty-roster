# ระบบจองเวรตรวจการ

เว็บแอปสำหรับ **จองเวรพยาบาลตรวจการ** นอกเวลาราชการและวันหยุดราชการ
พร้อม **พิมพ์เป็นเอกสารราชการ A4 ได้ทันที** ในรูปแบบเดิมทุกประการ

แทนที่การส่งไฟล์ Excel ไปมา ด้วยตารางที่ทุกคนเห็นตรงกันแบบเรียลไทม์

---

## ความสามารถ

| ส่วน | รายละเอียด |
|---|---|
| **ปฏิทินจองเวร** | ดูทั้งเดือนในหน้าเดียว แตะวันว่างเพื่อจอง เห็นการจองของคนอื่นทันทีโดยไม่ต้องรีเฟรช |
| **จองเอง + หัวหน้าอนุมัติ** | พยาบาลกดจองเอง สถานะเริ่มที่ "รออนุมัติ" หัวหน้าอนุมัติทีละรายการหรือทั้งเดือนรวดเดียว |
| **กันจองชนกัน** | บังคับที่ระดับฐานข้อมูล แม้กดพร้อมกันเป๊ะก็ได้คนเดียว |
| **ขอแลกเวร** | ส่งคำขอถึงเพื่อนร่วมงาน อีกฝ่ายกดรับ เวรจะโอนให้อัตโนมัติแล้วรออนุมัติใหม่ |
| **พิมพ์เอกสารราชการ** | A4 แนวตั้ง เลขไทย แถบเทาวันหยุด หัวคำสั่ง + ช่องลงนาม กด Ctrl/Cmd + P ใช้ได้เลย |
| **เตือนก่อนพิมพ์** | บอกว่ายังมีวันว่างกี่วัน และมีเวรรออนุมัติกี่รายการ |
| **สรุปภาระงาน** | จำนวนเวรต่อคน ดูความเป็นธรรมของการกระจายเวร |
| **ส่งออก CSV** | ทั้งปีในไฟล์เดียว เปิดด้วย Excel ภาษาไทยได้ทันที |
| **ใช้บนมือถือ** | ติดตั้งเป็นแอปบนหน้าจอหลักได้ (PWA) |
| **โหมดมืด** | สลับได้ที่แถบหัว |

---

## เทคโนโลยี

ไม่มี build step ไม่มี npm ไม่มี framework — แก้ไฟล์แล้วใช้ได้เลย

```
หน้าเว็บ:     HTML + CSS + JavaScript (ES modules) → GitHub Pages
ฐานข้อมูล:    Supabase (PostgreSQL + Row Level Security + Realtime)
ตัวอักษร:     Sarabun (Google Fonts)
```

---

## เริ่มใช้งาน

อ่าน **[docs/SETUP.md](docs/SETUP.md)** — 6 ขั้นตอน ประมาณ 20–30 นาที ทำครั้งเดียว

โดยสรุป:

1. สร้างโปรเจกต์ Supabase (ฟรี)
2. รัน SQL ไฟล์ `01`–`04` ในโฟลเดอร์ `supabase/` ตามลำดับ
3. ปิด **Allow new users to sign up** และ **Confirm email** ใน Authentication
4. รัน `supabase/05_create_logins.sql` สร้างบัญชีให้พยาบาลทุกคน
5. กรอก `supabaseUrl` + publishable key ใน `assets/js/env.js`
6. ตั้งหัวหน้าเวรคนแรกด้วย SQL หนึ่งบรรทัด

## ช่วงเวลาเวร

เอกสารราชการมี 3 คอลัมน์เวลาเสมอ แต่การปฏิบัติจริงคือ

| ช่วง | เวลา | การจอง |
|---|---|---|
| เวรเช้า | 08.30 – 16.30 น. | เปิดจองเฉพาะ**วันหยุดราชการ** |
| เวรบ่าย | 16.30 – 00.30 น. | จองคู่กับเวรดึกเสมอ (คนเดียวอยู่ยาว 16 ชม.) |
| เวรดึก | 00.30 – 08.30 น. | ↑ |

ปรับได้ที่ `PAIRED_SLOTS` และ `DAY_SLOT_HOLIDAY_ONLY` ใน `assets/js/config.js`

## ความปลอดภัยและความเป็นส่วนตัว

- **ทุกตารางเปิด RLS** — publishable key ที่เปิดเผยบนเว็บทำอะไรไม่ได้เกินสิทธิ์ที่กำหนด
  (ยืนยันด้วยการทดสอบจริง: คนไม่ล็อกอินอ่านตารางเวรได้ `[]` เขียนได้ `42501` สมัครสมาชิกได้ `signup_disabled`)
- พยาบาลแก้ได้เฉพาะเวรของตัวเองที่ยังไม่ถูกอนุมัติ
- **ตาราง `nurses` ไม่เปิดให้ผู้ใช้แก้แถวตัวเอง** — กันการตั้งตัวเองเป็นหัวหน้า
- เปลี่ยน PIN ผ่าน RPC `mark_pin_changed()` เท่านั้น
- บังคับเปลี่ยน PIN ตั้งต้นก่อนเริ่มใช้งาน และไม่รับ PIN ที่เดาง่าย
- ทุกการจอง/ยกเลิก/อนุมัติถูกบันทึกใน `audit_log` (อ่านได้เฉพาะหัวหน้า)
- **`04_seed.sql` ไม่ commit** เพราะมีชื่อ-นามสกุลเจ้าหน้าที่ — สร้างใหม่ได้จาก `.xlsx`
- Service Worker **ไม่ cache ข้อมูลเวร** เพื่อไม่ให้เห็นตารางเก่าแล้วจองซ้ำ

## การพัฒนาต่อ

ต้องการเซิร์ฟเวอร์ธรรมดาเพราะใช้ ES modules (เปิดไฟล์ตรงๆ ด้วย `file://` ไม่ได้):

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

ตรวจไวยากรณ์ก่อน commit:

```bash
for f in assets/js/*.js sw.js; do node --check "$f" || echo "ผิดพลาด: $f"; done
```
